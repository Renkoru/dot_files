#+TITLE: Moving from Evil to Meow — Migration Notes
#+DATE: 2026-06-28

* Why Meow?
- Meow blends modal editing into Emacs with *minimal interference* with standard Emacs keybindings.
- No more keybinding conflicts with packages like Magit, Org, Dired.
- Selection-first paradigm (Kakoune/Helix style): select, then act.  More visible, fewer mistakes.
- Lighter weight, better integrated with Emacs' built-in mechanisms.
- Fewer packages needed (no evil-collection, evil-surround, evil-goggles, etc.)

* Meow State Machine (Simplified)
  INSERT ←→ NORMAL ←→ MOTION
            ↕
          KEYPAD (for leader-based operations)
            ↕
          BEACON (visual/selection mode)

  Pressing SPC (leader) in NORMAL enters KEYPAD/LEADER mode.
  In MOTION mode, cursor movement expands/shrinks the selection.
  Operations (kill, change, copy) are applied to the selected region.

* Things You'll Need to Re-learn
1. **Selection-first paradigm**:
   Instead of =d w= (delete word), you press =SPC w= or enter motion
   mode and select first, then the operation applies automatically.
   In practice:
   - =d= in normal enters MOTION state. Move cursor to expand selection. Selection is auto-killed.
   - =c= in normal enters MOTION state. Move cursor to select. Region is killed, then INSERT mode.
   - =y= in normal enters MOTION state. Move cursor to select. Region is yanked.
   - =v= enters BEACON mode (visual). Same expand/shrink with cursor.

2. **Text objects are different**:
   - Evil: =v a f= selects "a function"
   - Meow: Use expand (=meow-expand=) and shrink (=meow-shrink=) to select by semantic units.
   - Alternatively, use =combobulate= for structured navigation.

3. **No evil-surround**: Use =embrace= package or meow's built-in =meow-save= for similar operations.
   - =embrace= works with =embrace-add= / =embrace-change= / =embrace-delete=
   - Or use =smartparens= for auto-pairing and wrapping.

4. **No evil-mc (multiple cursors)**: Instead, use:
   - =meow-visit=: search for pattern, then edit all matches simultaneously
   - Or =multiple-cursors= package (if really needed)

5. **Search**: Meow uses =/= and =?= for search (same keys!). =*= and =#= work for word under cursor.

6. **No evil-exchange**: Use =meow-swap-grab= to swap two regions.

7. **Window navigation**: =C-h/j/k/l= still work as before (bound in meow config).

* Tips for Smooth Transition
1. Keep this org file open during the transition.
2. The keybindings you use daily (SPC f, SPC a, SPC m, etc.) should work identically.
3. For basic editing: meow's QWERTY mode gives you hjkl, w/b/e, x, d, c, y, v, etc.
4. If something's missing, check this file first, then =SPC h f= (describe-function) to find meow equivalents.
5. Meow has a built-in cheatsheet: =M-x meow-cheatsheet=.
